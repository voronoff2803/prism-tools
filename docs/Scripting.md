# Scripts of rooms and obstacles

Generated by `Tools/scripts/scripting.py` from `Game/Script`: change the comments there, not this file.

A room and an obstacle are each a Lua script (Lua 5.2) with two functions the game calls: `init()` once, when the room or
the obstacle is made, and `tick()` every update (60 a second, fewer in slow motion: `mgGetTimeStep()` is the step). What a
script may call is below; `rooms/include.lua` is appended to every script (`confSegment`, `nextSegment` and other helpers of
the original game are there).

* **An obstacle** is `obstacles/<type>.lua`. A segment places it (`<obstacle type="..." param0="key=value" .../>`; in Blender
  an Empty of kind Obstacle), and the script reads its parameters with `mgGetInt("beams", 5)` and the like: the second value
  is what it is when the segment gives none. What it builds in `init()` (bodies, shapes, joints) is in its own frame: x to
  the right, y up, the corridor along -z.
* **A room** is `rooms/<room>.lua`: its `init()` sets the fog, the music and its segments one after another
  (`mgSegment(name, z)` returns the length) and says how long it is (`mgLength`). A room lasts one loop of its music, 32 s,
  whatever its length: the length is the camera's speed. The Blender add-on writes this script for a scene; turn "Generate
  script and level" off to write it by hand.
* **A level** is `levels/<name>.xml`: its rooms in order, and `<rules .../>` for the rules that are not the game's own
  (`GameRules` in `Game/Gameplay/GameRules.swift`: `startBalls`, `crashBallPenalty`, `crashGraceTime`, `streakTier`,
  `powerupDuration`, `powerupStackSize`, `frenzyShotInterval`, `slowMotionScale`, `ballSpeed`).

To try a script of your own without the repository: put it in the `Content` folder beside the `.blend`
(`Content/obstacles/mine.lua`), open the scene in a browser from the add-on, and it is read again whenever it is saved
(Tools/blender/README.md). The game's own scripts are the examples: `obstacles/*.lua` of the content.

| Call | What |
|---|---|

| `mgIsCleared()` | returns whether mgClear was called |
| `mgCanPass()` | returns nothing of this obstacle blocks the line x = 0, y = 1 through it |

| `mgCreateButton(x, y, z)` | returns button |
| `mgIsButtonDown(button [, edge])` | returns pressed (edge: pressed this update) |
